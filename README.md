# taskmanager
Python - Task Manager

•	Task Manager, using Python with Django and Django Rest Framework (DRF)

## Steps to Run
1. Download project
2. Open Terminal and navigate to project path
3. Type command ``` python manage.py runserver```
4. In the localhost URL tab inside the browser, append "/tasks" and press ENTER. <br/>
   For example:
   ``` http://127.0.0.1:8000/tasks/ ```
